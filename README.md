## 👨🏽‍💻 Sobre mim

### 🙋🏽 Quem sou eu?

Sou um **desenvolvedor Full Stack** com experiência principalmente no desenvolvimento de aplicações web utilizando **Angular, TypeScript, Java, Spring Boot e Express**.

Atualmente, atuo como **Desenvolvedor 1 na OAI**, trabalhando com desenvolvimento de aplicações e buscando constantemente evoluir minhas habilidades técnicas e ampliar meus conhecimentos em diferentes áreas da tecnologia.

Tenho experiência com **consumo e desenvolvimento de APIs REST, autenticação, integração entre sistemas, bancos de dados, deploy de aplicações e desenvolvimento de interfaces responsivas**.

🎓 Sou estudante de **Análise e Desenvolvimento de Sistemas**, e gosto de transformar ideias em soluções funcionais, buscando sempre escrever código organizado, sustentável e de fácil manutenção.

## 🐾 Projeto em destaque

<div align="center">

### Pet Points

**Sistema de gerenciamento para clínicas veterinárias com sistema de recompensas.**

</div>

O **Pet Points** é meu projeto de TCC e tem como objetivo centralizar o gerenciamento de uma clínica veterinária, oferecendo funcionalidades para diferentes perfis de usuários.

Entre os principais recursos estão:

* 🐶 Gerenciamento de tutores e pets
* 🩺 Gerenciamento de consultas
* 💊 Prontuários e informações veterinárias
* 💳 Pagamentos
* 📦 Controle de estoque
* 🛒 Loja virtual
* ⭐ Sistema de recompensas
* 🔐 Autenticação e controle de permissões
* 🔔 Sistema de notificações em tempo real

### Stack utilizada

`Angular` `TypeScript` `PrimeNG` `Java` `Spring Boot` `PostgreSQL` `JWT` `WebSocket`
